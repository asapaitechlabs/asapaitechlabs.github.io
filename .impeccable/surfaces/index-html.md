# Surface brief: homepage (index.html)

Scope: the whole one-page site at asapaitechlabs.com. Visitor mode: Persuade.
Audience: mixed (enterprise data/ML leaders, SMB owners new to AI, startups) deciding whether to trust ASAP.ai TECHLABS. Action: start a conversation (free 30-minute call or AI readiness assessment) via the contact form, email or phone.
Proof: the three case studies (5 markets, millions of listings, 500+ agreements), 10+ years, confirmed sectors. No delivery timeline may be stated (user: "not yet").
Constraints: one page; logo artwork and nav/footer lockup styling unchanged (white/cyan/silver Sora lockup forces a dark ground behind it); founder anonymous; no SOC 2/GDPR or partnership claims.
Build path: code-led (no image generation available).
Memorable moment: the hero pipeline whose input node is the call-to-action and whose last node is a live production system.

## Direction contract

THESIS: The page is drawn like the company's own system diagrams: an engagement is a pipeline from "your problem" to "running in production". It refuses the AI-consultancy default of a glowing dark hero, gradient headings, glass cards and a centred stack of identical sections.

OWN-WORLD: Two materials. Deep cobalt drawing field (#0a1c45 family) with hairline pale-blue line work, and cool white spec sheets (#f4f6fb) with ink-blue type for dense reading. Hexagon nodes from the logo mark as the one motif. Colour only as state: cyan = live/in production or current, amber = caution, red = alert. Archivo (expanded display, normal-width body), JetBrains Mono only for stacks and figures. No glow, gradient text, glass or decorative motion.

STORY: Visitors see the offer and how work flows, see three real systems in production, learn they work directly with a senior principal, see the process end in monitoring, then start a call through an honest form.

FIRST VIEWPORT: Left-aligned headline at display scale across the top two-thirds of width, sub-line and two actions beneath. A full-width pipeline band below: input node "Your problem" holds the primary action "Book a free 30-minute call", then Scope, Build, Check, Ship, and a final "Run" node with a live cyan signal. Nav: lockup, four links, "Book a call".

FORM: Engagement pipeline / system diagram, my list position 1 (user-pinned over roll assignment 4). Seed key 273965f2. Raises: Dive (one vertical axis rules every section: a left node-and-line spine), Instrument panel (colour only as status, trend and state shown), Greiman (scale jumps: billboard figures against footnote labels), Fletcher (each section leads with its figure; text confirms it).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
